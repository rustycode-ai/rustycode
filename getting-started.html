Installation

Download Binary (Recommended)

Download the latest release from GitHub Releases:

# macOS (arm64)
curl -LO https://github.com/rustycode-ai/rustycode/releases/download/v0.1.0/rustycode-macos-arm64.tar.gz
tar xzf rustycode-macos-arm64.tar.gz
chmod +x rustycode-macos-arm64
sudo mv rustycode-macos-arm64 /usr/local/bin/rustycode

# Windows (PowerShell)
Invoke-WebRequest -Uri https://github.com/rustycode-ai/rustycode/releases/download/v0.1.0/rustycode-windows-x64.zip -OutFile rustycode-windows-x64.zip
Expand-Archive rustycode-windows-x64.zip
# Move rustycode-windows-x86_64.exe somewhere in your PATH

Build from Source

git clone https://github.com/rustycode-ai/rustycode.git
cd rustycode
cargo build --release -p rustycode-cli
# Binary at target/release/rustycode-cli

Verify Installation

rustycode --version
# rustycode-cli 0.1.0

Configure API Keys

RustyCode reads API keys from environment variables:

# For Anthropic Claude (recommended)
export ANTHROPIC_API_KEY="sk-ant-your-key-here"

# For OpenAI GPT
export OPENAI_API_KEY="sk-your-key-here"
Tip: Add the export to your ~/.zshrc or ~/.bashrc so it persists across sessions. Never commit API keys to source control.

You can also use a local LLM via Ollama — no API key required:

# Install and start Ollama
ollama serve
ollama pull codellama

# Configure RustyCode to use Ollama (see configuration.html)

Your First Run

Interactive TUI Mode

cd your-project-directory
rustycode tui

This opens the terminal UI. Type your request and press Enter. RustyCode will:

  1. Analyze your codebase context
  2. Plan an approach using structured reasoning
  3. Execute changes using file editing and shell tools
  4. Show results and ask for confirmation when needed

Headless CLI Mode

rustycode run "Add error handling to the database connection function"

Tool Approvals

When RustyCode wants to run a tool (edit a file, run a command), the TUI shows the proposed action and asks for your approval. You can:

  • Approve — let the tool execute
  • Deny — block the action
  • Auto-approve — approve all subsequent actions for this session

Headless Mode

Run RustyCode without a TUI for scripting and automation:

# Single task
rustycode run "Fix the off-by-one error in parser.rs"

# With specific provider
rustycode run --provider openai "Refactor the auth module"

# With timeout
rustycode run --timeout 300 "Implement the full user registration flow"
