Getting Started

Get up and running with RustyCode in a few minutes. We'll guide you through prerequisites, installation, API key configuration, and running your first task.

Prerequisites

Ensure your system meets the following minimal requirements before running RustyCode:

RequirementDetails
Operating SystemmacOS (Apple Silicon / Intel), Windows (x64), Linux (amd64 / arm64)
API KeyAnthropic Claude, OpenAI, Google Gemini, or Ollama (fully local models)
TerminalAny modern terminal with TrueColor (24-bit) support (e.g., iTerm2, Alacritty, Kitty, Windows Terminal)
Optional ToolsNode.js & npm (required to install and run third-party MCP servers)

Installation

One-Line Install (Recommended)

The easiest way to install RustyCode is using our official shell script or PowerShell script. This downloads the latest release binary for your platform and puts it in your path.

# macOS / Linux
curl -fsSL https://rustycode-ai.github.io/install.sh | sh

# Windows (PowerShell)
irm https://rustycode-ai.github.io/install.ps1 | iex

# Nightly channel (installs the latest commit build)
curl -fsSL https://rustycode-ai.github.io/install.sh | sh -s -- --nightly

Download Pre-built Binary

Alternatively, fetch assets directly from the GitHub Releases Page:

PlatformAsset Name
macOS (Apple Silicon)rustycode-macos-arm64.tar.gz
Linux (x64)rustycode-linux-x64.tar.gz
Linux (arm64)rustycode-linux-arm64.tar.gz
Windows (x64)rustycode-windows-x64.zip

Build from Source

If you have the Rust toolchain installed, you can clone and build RustyCode manually. Make sure to target the main CLI crate:

git clone https://github.com/luengnat/rustycode.git
cd rustycode
cargo build --release -p rustycode-cli

# The compiled binary will be placed at:
# target/release/rustycode-cli

Verify Installation

rustycode --version

Configure API Keys

RustyCode reads API keys from environment variables. Export them in your shell session or save them to your profile (e.g., ~/.zshrc, ~/.bashrc):

# Anthropic Claude (recommended model: claude-sonnet-4-6)
export ANTHROPIC_API_KEY="sk-ant-your-key-here"

# OpenAI (recommended model: gpt-4o or o3)
export OPENAI_API_KEY="sk-your-key-here"

# Google Gemini (recommended model: gemini-2.5-pro)
export GOOGLE_API_KEY="AIzaSyYourKeyHere"
💡
Tuning Settings:

You can also customize default providers, models, and execution budgets in your global configuration file (located at ~/.rustycode/config.toml). See the Configuration Guide for more details.

Ollama (Fully Local Setup)

Run RustyCode completely offline. No API key or internet connection required:

# Install Ollama (https://ollama.com) and serve it
ollama serve

# Pull a strong coding model
ollama pull deepseek-coder-v2

# Configure Ollama in ~/.rustycode/config.toml:
# [provider]
# default = "ollama"
# [provider.ollama]
# base_url = "http://localhost:11434"
# model = "deepseek-coder-v2"

Your First Run

Open a terminal, navigate to your codebase directory, and boot the framework:

Interactive Terminal UI (TUI)

cd /path/to/your/project
rustycode tui

This boots RustyCode's interactive screen. Type your request and press Enter. The framework will:

  1. Analyze your repository structure and build a context map
  2. Formulate a phase-by-phase execution plan
  3. Execute edits and run validation checks using specialized tools
  4. Prompt you for approval when performing stateful operations (like edits or shell executions)

TUI Basics

Navigate the TUI environment using the following key bindings:

  • Ctrl+1-9
    • ShortcutAction
    EnterSend message / Submit tool approval
    EscapeClose help/overlay / Cancel mode transition
    Ctrl+CStop/abort the current model streaming or running tool
    Ctrl+QQuit RustyCode
    Ctrl+BToggle sessions sidebar
    Ctrl+KOpen command palette (quick actions)
    Ctrl+FSearch within current conversation messages
    Switch tabs/sessions directly

    Web UI & Vision Support

    RustyCode has a built-in React web dashboard, providing a visual browser interface:

    # Start the web UI server
rustycode web start

# Or start the unified backend API server (runs Web, ACP, and A2A servers)
rustycode serve

    Access the panel at http://localhost:3000. Key features include:

    • Vision Input: Drag or paste images (screenshots, UI mockups) directly into the chat prompt to enable visual reasoning.
    • Approval Panel: Interactive review overlays showing file diffs side-by-side.
    • Command Palette: Ctrl+K menu to run shortcuts, load workflows, or toggle models.

    Headless CLI Mode

    For script integration and one-shot execution, bypass the UI entirely:

    # Run a quick fix
rustycode run "Fix the syntax warnings in src/auth.rs"

# Override model and provider for a specific run
rustycode run --provider google --model gemini-2.5-pro "Generate unit tests for src/utils.rs"

# Run with a budget timeout (seconds)
rustycode run --timeout 300 "Refactor the config loader to handle YAML format"
