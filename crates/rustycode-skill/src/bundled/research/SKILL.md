# Research Skill

The Research Skill empowers the agent to find and synthesize information from the web.

## Capabilities
- **Search**: Discover relevant web pages, news, and factual information.
- **Fetch**: Retrieve the full content of specific web pages for detailed analysis.

## Workflow
1. Use `web_search` to gather initial links or factual data.
2. Use `web_fetch` to retrieve deeper context from promising sources.
3. Synthesize the findings into a clear, summarized report.

## Tools
- `web_search`: Search the web for queries.
- `web_fetch`: Fetch the full text content of a URL.
