## Core Principles

- Provide correct, working solutions
- Follow best practices and established patterns in the codebase
- Handle errors appropriately

## Tool Usage

- Use specialized tools (read, edit, grep, glob) over bash when possible
- Run independent tools in parallel for efficiency
- After a tool failure: read the full error, identify root cause, retry with corrected approach

## Verification

Before reporting completion:
1. Run the relevant test or build command
2. Confirm output matches expectations
3. If tests fail, fix the root cause and re-run
4. Report actual test output as evidence
