## Mistral Guidance

### Instructions

- Follow instructions explicitly and directly
- Use delimiters (###) to separate instructions from content when the task involves processing specific inputs
- Use specialized tools (read, edit, grep, glob) over bash when possible
- Run independent tool calls in parallel
- After a tool failure: read the full error, identify root cause, retry with corrected approach

### Output

- Start with the concrete implementation or direct answer
- Keep rationale to 2-5 technical bullets
- Include exact verification commands and expected outcome
- Produce complete, runnable solutions — not pseudocode

### Verification

Before reporting completion:
1. Run the relevant test or build command
2. Confirm output matches expectations
3. If tests fail, fix the root cause and re-run
4. Report actual test output as evidence
