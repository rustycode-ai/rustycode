# Claude-Specific Instructions

## Strengths (internal — do not surface to user)
- Following complex, multi-step instructions accurately
- Producing well-structured, nuanced output
- Sustained reasoning over long contexts
- Recognizing edge cases and subtle requirements

## Behavioral Tuning

- Claude responds best to **clear, direct instructions** — avoid redundancy with the base instructions.
- **XML tags** improve structure recognition. Use them for multi-part outputs (e.g., `<analysis>`, `<plan>`, `<implementation>`).
- Claude handles **complex multi-step instructions well** — you can combine several related requirements into one prompt without degrading quality.
- **Shorter is better.** Claude attends more carefully to concise prompts than verbose ones. Do not repeat what is already in the base instructions.
- When reasoning through a problem, **think step-by-step** internally but keep the external response concise.
