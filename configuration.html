Configuration Reference

RustyCode is configured using TOML files and environment variables. This reference explains how to structure your configurations globally and locally.

Config Locations

RustyCode reads configuration files sequentially, applying project-level overrides on top of user-level defaults:

PriorityPathDescription
1 (Base) ~/.rustycode/config.toml Global configurations. Put API keys and personal defaults here.
2 .rustycode/config.toml Project-level overrides. Put project models and custom tools here.
3 CLAUDE.md Workspace instructions. Read automatically to guide code style and paths.
4 (Highest) Environment Variables Keys prefixed with RUSTYCODE_ override config file settings at runtime.

Full TOML Sample

Here is a complete, fully featured config.toml showcasing all available tables:

# ~/.rustycode/config.toml

# ── Provider Settings ──────────────────────────────────────
[provider]
# Default active provider
default = "anthropic"

# ── Anthropic Claude ───────────────────────────────────────
[provider.anthropic]
api_key_env = "ANTHROPIC_API_KEY"
model = "claude-sonnet-4-6"
max_tokens = 8192
temperature = 0.0

# ── OpenAI ─────────────────────────────────────────────────
[provider.openai]
api_key_env = "OPENAI_API_KEY"
model = "gpt-4o"
max_tokens = 4096
temperature = 0.0

# ── Google Gemini ──────────────────────────────────────────
[provider.google]
api_key_env = "GOOGLE_API_KEY"
model = "gemini-2.5-pro"
max_tokens = 8192

# ── Google Cloud Vertex AI ─────────────────────────────────
[provider.vertex]
project_id = "your-gcp-project"
location = "us-central1"
model = "gemini-2.5-pro"

# ── Amazon Bedrock ─────────────────────────────────────────
[provider.bedrock]
model = "anthropic.claude-sonnet-4-20250514"
region = "us-east-1"

# ── Azure OpenAI ───────────────────────────────────────────
[provider.azure]
api_key_env = "AZURE_OPENAI_API_KEY"
base_url = "https://your-resource.openai.azure.com"
deployment = "gpt-4o"
api_version = "2024-08-01"

# ── Ollama (Local) ─────────────────────────────────────────
[provider.ollama]
base_url = "http://localhost:11434"
model = "deepseek-coder-v2"

# ── MCP Server Hookups ─────────────────────────────────────
[[mcp_server]]
name = "postgres"
transport = "stdio"
command = "npx"
args = ["-y", "@modelcontextprotocol/server-postgres", "postgresql://localhost/mydb"]

# ── Agent-to-Agent (A2A) ───────────────────────────────────
[a2a]
enabled = false
port = 8080

# ── Security & Tool Permissions ─────────────────────────────
[permissions]
# Sensitive file extensions and directories blocked from agent access
protected_paths = [
  ".env", "*.pem", "*.key", "id_rsa", "credentials.json", "terraform.tfstate"
]
# Commands the agent can execute without user approval
auto_approve_commands = [
  "ls", "cat", "head", "tail", "wc", "find", "grep",
  "git status", "git log", "git diff", "cargo check", "cargo clippy"
]

# ── Orchestration Tuning ───────────────────────────────────
[orchestration]
# Maximum iterations the autonomous agent loop can run (default: 3)
max_iterations = 3
# Maximum tool turns per prompt iteration (default: 25)
max_tool_turns = 25
# Wall-clock timeout before forcing stop (default: 900 seconds)
wall_clock_timeout_secs = 900
# Minimum tool invocations before concluding a task (default: 5)
min_tool_calls_to_stop = 5

LLM Providers

Anthropic

Recommended for its coding capability. Set ANTHROPIC_API_KEY. Recommended models:

  • claude-sonnet-4-6: Balanced model for feature development and editing.
  • claude-opus-4-7: High-effort model for architecture and diagnostics.
  • claude-haiku-4-5: Fast and cost-efficient option for simple, single-file patches.

Google Cloud Vertex AI

Utilize corporate Gemini models hosted via Google Cloud Vertex. Ensure the local environment has active credentials via gcloud auth application-default login, then set:

[provider.vertex]
project_id = "my-gcp-project-123"
location = "us-central1"
model = "gemini-2.5-pro"

Ollama

Configure a custom model registry endpoint. Set base_url to your local port (default http://localhost:11434) and choose your downloaded model (e.g. deepseek-coder-v2 or codellama).

MCP Configurations

Define third-party MCP servers under the [[mcp_server]] array. Define environment variables in an optional env table block:

[[mcp_server]]
name = "github"
transport = "stdio"
command = "npx"
args = ["-y", "@modelcontextprotocol/server-github"]
env = { GITHUB_PERSONAL_ACCESS_TOKEN = "ghp_..." }

Permissions & Paths

Protect sensitive system configs and user directories using security tables:

  • protected_paths: Glob paths matches. If the agent attempts to read, write, or grep files matching these patterns, the security manager throws a validation error and aborts the operation.
  • auto_approve_commands: Standard commands the agent runs automatically. Any shell command not in this list prompts the user with an explicit TUI/Web confirmation dialog before execution.

Orchestration & Budgets

Prevent runaway loops and coordinate agent workloads. Configurable options:

SettingDefaultDescription
max_iterations 3 Determines how many full reasoning attempts (planning, acting, verifying) the agent can perform.
max_tool_turns 25 Limits total tool execution loops per task run to prevent endless recursion.
wall_clock_timeout_secs 900 Hard wall-clock timeout. Forces the agent to shut down and output results.
min_tool_calls_to_stop 5 Ensures the agent doesn't quit immediately without performing sufficient validation.

Environment Variables

Override TOML files at runtime using environment variables:

VariableTOML OverrideExample
RUSTYCODE_PROVIDER provider.default export RUSTYCODE_PROVIDER="google"
RUSTYCODE_MODEL_OVERRIDE Active model name export RUSTYCODE_MODEL_OVERRIDE="gpt-4o"
RUSTYCODE_EFFORT_OVERRIDE Reasoning effort limit export RUSTYCODE_EFFORT_OVERRIDE="medium"
RUSTYCODE_SKIP_PERMISSIONS Skips security checks export RUSTYCODE_SKIP_PERMISSIONS="true"
RUSTYCODE_CONFIG Custom config file path export RUSTYCODE_CONFIG="/tmp/config.toml"
