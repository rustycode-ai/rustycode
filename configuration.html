Config File

RustyCode reads configuration from ~/.rustycode/config.toml (create it if it doesn't exist):

# ~/.rustycode/config.toml

[provider]
# Default LLM provider
default = "anthropic"

[provider.anthropic]
api_key_env = "ANTHROPIC_API_KEY"
model = "claude-sonnet-4-6"

[provider.openai]
api_key_env = "OPENAI_API_KEY"
model = "gpt-4o"

[provider.ollama]
base_url = "http://localhost:11434"
model = "codellama"

[orchestration]
max_iterations = 3
max_tool_turns = 25
wall_clock_timeout_secs = 900
min_tool_calls_to_stop = 5

[permissions]
# Files that require explicit approval to edit
protected_paths = [".env", "Cargo.toml", "package.json"]
# Commands that are auto-approved (read-only)
auto_approve_commands = ["ls", "cat", "git status", "git log", "git diff"]

[tui]
theme = "dark"
scrollback = 10000

Provider Settings

Anthropic Claude

[provider.anthropic]
api_key_env = "ANTHROPIC_API_KEY"
model = "claude-sonnet-4-6"     # or claude-opus-4-7, claude-haiku-4-5
max_tokens = 8192
temperature = 0.0

OpenAI

[provider.openai]
api_key_env = "OPENAI_API_KEY"
model = "gpt-4o"                # or gpt-4o-mini, gpt-4-turbo
base_url = ""                   # Optional: custom endpoint

Ollama

[provider.ollama]
base_url = "http://localhost:11434"
model = "codellama"             # or llama3, mistral, deepseek-coder
Tip: You can define multiple providers and switch between them at runtime with the --provider flag, without changing the config file.

Tool Permissions

Auto-Approved Commands

These read-only commands run without asking for approval:

ls, cat, head, tail, wc, find, grep,
git status, git log, git diff, git branch,
cargo check, cargo test, cargo clippy,
python3 --version, node --version

Blocked Patterns

These are always blocked for safety:

# Files
.env, .env.*, credentials.json, id_rsa, *.pem, terraform.tfstate

# Command flags
python -c "..."    # eval flag blocked for all interpreters
bash -c "..."      # same for bash
