# Flow2026: Adaptive Reasoning & Orchestration Implementation Plan

## Executive Summary
This project aims to evolve the current RustyCode orchestration pipeline into a fully autonomous, self-correcting development flow. We are moving from simple task execution to a "Thinking-First" architecture where the agent orchestrates its own reasoning, validates its own hypothesis, and learns from failures in real-time.

---

## Phase 1: The Adaptive Core
*   **Quality-First Routing**: Implement a pre-execution quality check. Every output is evaluated by a "self-reflection" prompt before it is allowed to progress to TUI output or execution.
*   **Strategy Engine**: Based on task complexity (detected via history) and quality score, choose one of:
    *   `DirectExecution` (for simple tasks)
    *   `QuickSelfEval` (for moderate tasks)
    *   `PhasedOrchestration` (for complex architecture/system tasks)
*   **Learning DB**: Log outcomes in a local SQLite DB (`LearningDb`) to track which LLM model + strategy combination yields the highest quality for specific task types.

## Phase 2: Structural Memory (Graph-of-Thoughts)
*   **Persistence**: Store all reasoning steps as a `ReasoningGraph` in a structured format (JSONL per phase).
*   **Context Compression**: When switching phases, summarize the graph instead of passing the full chat history. Use the `ReasoningStore` to manage retrieval of past decisions/constraints.

## Phase 3: TUI Orchestration Integration
*   **Visualization**: Real-time TUI modal showing the `ReasoningGraph` (Nodes: Thoughts/Hypotheses, Edges: Dependencies/Validation).
*   **Feedback Loop**: Allow users to interact with thoughts (expand, branch, reject) directly in the UI.

## Phase 4: Validation (The Harness)
*   **Terminal-Bench 2**: Execute against 50+ benchmark tasks.
*   **Regression Suite**: Ensure 90%+ success on simple tasks, 60%+ on complex tasks.
*   **Optimization Loop**: Use the `LearningDb` to automatically suggest optimal strategy parameters for the Conductor.

## Success Criteria
1.  **Complexity detection**: System correctly identifies task complexity > 80% of the time.
2.  **Reasoning Transparency**: Users can view the reasoning graph while it evolves.
3.  **Self-Correction**: System detects its own hallucinations via the quality detector and triggers an escalation/re-think.
4.  **Learning**: The `LearningDb` shows measurable success rate improvement over 50 iterations.
