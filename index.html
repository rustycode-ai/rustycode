What RustyCode Does

RustyCode isn't a chat wrapper — it's a complete development agent. Give it a task and it will reason through the problem, make changes, run tests, and verify the result. It works across your entire codebase with structured planning and quality gates.

1

Plan & Reason

Analyzes your codebase, breaks tasks into steps, and creates an execution plan with dependencies and milestones.

2

Execute & Iterate

Reads files, writes code, runs commands, and edits with flexible matching. Each step is verified before moving on.

3

Verify & Recover

Runs your tests, checks diagnostics, and validates changes. If something goes wrong, it recovers from checkpoints.

4

Report & Notify

Summarizes what changed, what passed, and what needs attention. Get notified via Discord, Slack, or Telegram.

Use Cases

Bug Fixes

Point RustyCode at a failing test or error log. It traces the root cause, applies the fix, and verifies tests pass.

Feature Implementation

Describe the feature. RustyCode plans the implementation, writes code across multiple files, and runs the test suite.

Code Review

Feed a PR diff. RustyCode identifies bugs, security issues, style violations, and suggests improvements.

Refactoring

Rename symbols, extract modules, migrate patterns — all verified by tests at each step.

Documentation

Generate README files, API docs, inline comments, and architecture docs from your actual codebase.

Security Auditing

Scan for hardcoded secrets, injection vulnerabilities, and misconfigurations with built-in security tools.

Quick Start

# Set your API key

rustycode run "Fix the off-by-one error in src/parser.rs"

# Web interface — browser-based
rustycode web
