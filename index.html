RustyCode

AI-powered autonomous development framework. Built in Rust for speed, reliability, and full control over your codebase.

Get Started Download Binary

One-Line Install

# macOS / Linux
curl -fsSL https://rustycode-ai.github.io/rustycode/install.sh | sh

# Windows (PowerShell)
irm https://rustycode-ai.github.io/rustycode/install.ps1 | iex

Features

⚡

Autonomous Mode

Plan, execute, and verify tasks autonomously with structured reasoning, quality gates, and checkpoint recovery.

🤖

15+ LLM Providers

Full support for Anthropic Claude, OpenAI GPT, Google Gemini (including Vertex AI), Amazon Bedrock, Azure, Ollama, Cohere, Mistral, Together AI, and more.

💻

Terminal UI (TUI)

A beautiful ratatui-based TUI with streaming, cost tracking, tabbed multi-session support, and keyboard shortcuts.

🌐

Web UI & Vision

React-based interface with session management, tool approvals, command palette, and image paste/upload with vision model support.

🔗

Multi-Agent Teams

Coordinate multiple specialized agents in parallel (Ensemble Mode) with git worktree isolation and unified quality gate checking.

🚀

Dynamic Workflows

Run static DAGs or script dynamic tasks with Rhai-scripted workflows. Features adversarial review verification and blind judge scoring.

💲

Model Tiering & Advisor

Consult a cheap model for standard tool execution loops, and spawn cost-effective senior consults using the /advisor command.

🛡

Intelligence Guards

Avoid runaways and infinite loops with streaming repetition detection, repeated-failure blocks, context budgets, and stuck-loop warnings.

🌙

Advanced Computer Use

Desktop control via MCP: screenshots, clicks, typing, and drag. Features macOS, Linux, and Windows surface-aware routing.

📚

YAML Skill System

Markdown and YAML frontmatter-based skill discovery. Browse, install, and update custom tools/skills from the marketplace.

📑

Wiki & Learning

SQLite FTS5-powered wiki, cross-session knowledge consolidation, and citation tracking to retain fixes permanently.

🔒

Security First

Command sandboxing (macOS Seatbelt, Linux Landlock), protected file path validations, secret sanitization, and manual tool approvals.

Quick Start

# Set your API key
export ANTHROPIC_API_KEY="sk-ant-..."

# Start the TUI
rustycode tui

# Run headless
rustycode run "Fix the bug in src/main.rs"

# Start the web interface
rustycode web start

Architecture

RustyCode is a highly modular system structured across several layers in a workspace of 70 crates:

CLI & TUI

Interactive interfaces built with ratatui and React, featuring streaming outputs, cost monitors, and approval menus.

Orchestration

Autonomous loops, AST validation pipelines, stuck loop diagnostics, and senior-junior model tiering.

LLM Providers

Unified LLMProvider trait mapping to 15+ services with automatic model routing and token budget tracking.

Tools & MCP

20+ built-in file and search tools, dynamic MCP client, and built-in servers (browser, docker, web, computer-use).

Storage & Session

SQLite persistence layer for conversations, artifacts, and search, tied together by a real-time event bus.

Security & Protocols

OS sandboxing, file/command validation, ACP server for IDE support, and A2A protocol for inter-agent communication.
