RustyCode

AI-powered autonomous development framework. Built in Rust for speed, reliability, and full control over your codebase.

Get Started Download

One-Line Install

# macOS / Linux
curl -fsSL https://rustycode-ai.github.io/install.sh | sh

# Windows (PowerShell)
irm https://rustycode-ai.github.io/install.ps1 | iex

Quick Start

# Set your API key
export ANTHROPIC_API_KEY="sk-ant-..."

# Start the TUI
rustycode tui

# Or run headless
rustycode run "Fix the bug in src/main.rs"

# Start web interface
rustycode web start

Architecture

RustyCode is a modular workspace of 70+ focused crates:

CLI & TUI

Interactive terminal and web interfaces with streaming, tool monitoring, multi-session, and keyboard shortcuts.

Orchestration

Autonomous execution with reasoning loops, quality gates, AST pipeline, session handoff, and milestone sequencing.

LLM Providers

Unified provider trait supporting 15+ providers with model routing, token budgets, and streaming state management.

Tools & Skills

20+ built-in tools, extensible framework, YAML skills with marketplace, and MCP server discovery.

Protocols

MCP client for tool discovery, ACP server for IDE integration, A2A for inter-agent communication.

Storage & Session

SQLite persistence for sessions, artifacts, handoff history, and wiki. Event bus for real-time pub/sub.

Security

Permission system, path validation, command sandboxing (Seatbelt/landlock), and secret sanitization.

Team & Bench

Multi-agent coordination, task profiling, and rustycode-bench for native/Docker benchmark evaluation.
