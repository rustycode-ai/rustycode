Quick Install

# macOS (arm64)
curl -LO https://github.com/rustycode-ai/rustycode/releases/download/v0.1.0/rustycode-macos-arm64.tar.gz
tar xzf rustycode-macos-arm64.tar.gz
chmod +x rustycode-macos-arm64
sudo mv rustycode-macos-arm64 /usr/local/bin/rustycode

# Windows (x64)
curl -LO https://github.com/rustycode-ai/rustycode/releases/download/v0.1.0/rustycode-windows-x64.zip
Expand-Archive rustycode-windows-x64.zip
# Move rustycode-windows-x86_64.exe to your PATH

Quick Start

# Set your API key
export ANTHROPIC_API_KEY="sk-ant-..."

# Start the TUI
rustycode tui

# Or run headless
rustycode run "Fix the bug in src/main.rs"

Architecture

RustyCode is organized as a modular workspace of focused crates:

CLI & TUI

Interactive terminal interface with streaming responses, tool monitoring, and keyboard shortcuts.

Orchestration

Autonomous execution engine with reasoning loops, quality gates, and strategy management.

LLM Providers

Unified provider trait supporting Anthropic, OpenAI, Ollama, and custom endpoints.

Tools

File editing, bash execution, grep, glob, LSP integration, and extensible tool framework.

Event Bus

Publish/subscribe event system for real-time communication between components.

Benchmark

rtk-bench: native and Docker-based benchmark runner for agent evaluation.
