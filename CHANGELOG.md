## [0.1.0] - 2026-05-07

Initial release of RustyCode — an AI-powered autonomous development framework built in Rust.

### Highlights

- **Interactive TUI** — Terminal UI with streaming LLM output, session management, slash commands, and multi-panel layout
- **12 LLM Providers** — Anthropic Claude, OpenAI, Google Gemini, OpenRouter, Ollama, and more
- **Autonomous Orchestration** — Milestone-based execution with quality gates, reasoning loops, and tiered model selection
- **20+ Built-in Tools** — File read/write/edit, bash execution, grep, glob, LSP integration, web fetch, notebook editing
- **Multi-Agent Teams** — Spawn, coordinate, and cancel agents with role-based collaboration
- **Cross-Platform** — macOS (ARM64/x64), Linux (ARM64/x64), Windows (x64)
- **Self-Update** — `rustycode update` for one-command upgrades
- **Sandboxing** — macOS Seatbelt and Linux landlock isolation for safe tool execution
- **Skill System** — Extensible YAML frontmatter skills with discovery and lifecycle management
- **Session Persistence** — Record, replay, and switch between conversation sessions
- **10,000+ Tests** — Comprehensive test suite across 48 crates
