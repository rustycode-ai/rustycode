Autonomous Mode

RustyCode's autonomous mode uses structured reasoning to plan and execute multi-step tasks:

  1. Analysis — Reads your codebase, identifies relevant files and context
  2. Planning — Creates a structured plan with phases and dependencies
  3. Execution — Runs tools in sequence, adapting based on results
  4. Verification — Runs tests, checks builds, validates changes
  5. Quality Gates — Ensures code quality before marking tasks complete

Execution Parameters

ParameterDefaultDescription
MAX_ITERATIONS3Maximum reasoning iterations
MAX_TOOL_TURNS25Maximum tool calls per task
DEFAULT_WALL_CLOCK_TIMEOUT_SECS90015-minute wall-clock timeout
MIN_TOOL_CALLS_TO_STOP5Minimum tool calls before considering completion

Stuck Detection

The autonomous engine detects when it's stuck via:

  • Confidence stagnation over multiple iterations
  • Repetition of the same approach
  • Excessive reasoning phases without progress

When stuck, RustyCode surfaces a warning and may ask for clarification.

Permission System

RustyCode validates all operations through its security layer:

  • Path validation — Blocks access to sensitive files (`.env`, credentials, SSH keys)
  • Command validation — Validates shell commands before execution
  • Secret sanitization — API keys are stripped from logs and debug output
  • Eval blocking — Blocks -c/-e flags for interpreters
  • Filename blocking — Blocks credentials.json, id_rsa, terraform.tfstate, etc.

Blocked File Patterns

.env, .env.*, credentials.json, config.json,
id_rsa, id_ed25519, *.pem, *.key,
terraform.tfstate, *.tfstate.backup

Benchmark Runner

rustycode-bench evaluates agent performance on standardized coding tasks:

# Run benchmarks natively
cargo run -p rustycode-bench -- --native --timeout 120

# Run in Docker
cargo run -p rustycode-bench -- --docker --timeout 300

# Filter tasks with regex
cargo run -p rustycode-bench -- --native --include "regex-.*" --timeout 120

# Output formats
cargo run -p rustycode-bench -- --native --output json
cargo run -p rustycode-bench -- --native --report markdown

Features

  • Native and Docker execution modes
  • Exception-based retry filtering (include/exclude regex)
  • Result history store with diff comparison
  • Multiple output formats: pretty, JSON, CSV, Markdown
  • Composite dataset merging with deduplication
